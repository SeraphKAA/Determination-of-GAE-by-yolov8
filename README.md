# Determination-of-GAE-by-yolo

Определение **пола**, **возраста** и **этноса** по фотографиям на основе трёх отдельных моделей YOLOv8.

## Возможности

- Графический интерфейс на **PyQt6**
- Загрузка изображений форматов **JPG**, **JPEG**, **PNG**
- Автоматическое преобразование **JPG/JPEG → PNG** для дальнейшей обработки
- Одновременная или выборочная детекция по трём моделям:
  - `app/best_gender.pt` — пол
  - `app/best_age.pt` — возраст
  - `app/best_ethnos.pt` — этнос
- Отображение исходного изображения слева и результата детекции справа
- Текстовый вывод найденного класса и процента уверенности

## Требования

- Python 3.10+
- Файлы моделей в каталоге `app/`:
  - `best_gender.pt`
  - `best_age.pt`
  - `best_ethnos.pt`

## Установка

1. Клонирование репозитория и выбор каталога:

```bash
git clone <url-репозитория>
cd Determination-of-GAE-by-yolov8
```

2. Создание виртуального окружения:

```bash
python -m venv .venv
source .venv/bin/activate   # Linux / macOS
.venv\Scripts\activate    # Windows
```

3. Установите зависимости:

```bash
pip install -r requirements.txt
```

### WSL / Linux

Для отображения окна нужен графический сервер (WSLg в Windows 11 или X-сервер). Если окно не открывается, попробуйте:

```bash
export QT_QPA_PLATFORM=xcb
python3 app/main.py
```

## Запуск GUI

Из корня проекта:

```bash
python app/main.py
```

## Как пользоваться

1. Запустите приложение командой выше.
2. Дождитесь сообщения **«Модели загружены»** в верхней части окна.
3. Нажмите **«Выбрать изображение»** и укажите файл `.jpg`, `.jpeg` или `.png`.
4. Слева отобразится исходное изображение, справа — результат детекции.
5. Используйте чекбоксы **Пол**, **Возраст**, **Этнос**, чтобы включать или скрывать соответствующие детекции на результирующем изображении.
6. В нижней части окна смотрите текстовый результат: название класса и уверенность в процентах.

### Примечания

- Файлы **JPG/JPEG** при выборе автоматически конвертируются в **PNG** (рядом с исходным файлом создаётся `.png` с тем же именем).
- Если для какой-то модели объекты не найдены, в текстовом блоке будет указано **«объекты не найдены»**.
- Порог уверенности детекции: **25%** (`conf=0.25`).

## Обучение моделей

Обучение выполняется отдельно для каждого датасета через `train/main.py` и Ultralytics YOLO. Подробности настройки датасета смотрите в конфигурации `data.yaml` вашего набора данных.

|-----------------|-------------------------------------|

| opencv-python   | обработка изображений               |
| pillow          | конвертация JPG/JPEG в PNG          |
| PyQt6           | графический интерфейс               |
| torch           | backend для нейросетей              |

Полный список версий — в `requirements.txt`.
